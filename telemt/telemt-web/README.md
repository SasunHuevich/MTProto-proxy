### Небходимые утитлиты
- curl
- openssl
- docker
- docker compose

### Что это
WEB-прокси для Telegram на [telemt](https://github.com/telemt/telemt). Ссылка `tg://webproxy` вставляется прямо в Telegram.

Трафик идёт как обычный HTTPS к вашему сайту: настоящий сертификат Let's Encrypt (Caddy), TLS-отпечаток браузерного движка внутри Telegram. Поэтому блокировка FakeTLS по отпечатку клиента Telegram на него не действует. Кто зайдёт на домен без ключа — увидит сайт-заглушку из `site/`.

### Какие клиенты поддерживают
- Telegram Desktop 7.1+
- Android — экспериментально, в свежих версиях
- iOS — в зависимости от версии, лучше проверить на месте

Звонки через прокси не работают (ограничение Telegram).

### Подготовка
1. Домен (можно поддомен), A-запись на IP сервера
2. Вписать домен в `settings.env`
3. Открыть порты 80 и 443. Порт только 443 — Telegram других для WEB не поддерживает

### Использование
- `./start_proxy.sh` — запуск, при первом запуске создаёт клиента `default`
- `./add_client.sh <имя>` — новый клиент, выдаёт ссылку `tg://webproxy`
- `./remove_client.sh <имя>` — отозвать доступ
- `./show_clients.sh` — все ссылки
- `./stop_proxy.sh`

Добавление и удаление клиентов подхватывается без перезапуска.

Занимает 443 порт целиком — на одном сервере с `telemt/telemt`, `xtls/xray` или `nineseconds/mtg` не запустить.

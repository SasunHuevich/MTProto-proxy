### Небходимые утитлиты
- curl
- openssl
- docker
- docker compose

### Что это
MTProto-прокси [telemt](https://github.com/telemt/telemt) с FakeTLS под ваш домен. Ссылки `tg://proxy` вставляются прямо в Telegram, у каждого клиента свой секрет.

Рядом работает Caddy с сайтом-заглушкой из `site/` и настоящим сертификатом Let's Encrypt. Всё, что пришло без ключа прокси (сканеры, браузер), получает обычный сайт.

### Подготовка
1. Купить домен, сделать A-запись на IP сервера
2. Вписать домен в `settings.env`
3. Открыть порты 80 (выпуск сертификата) и 443

### Использование
- `./start_proxy.sh` — запуск, при первом запуске создаёт клиента `default`
- `./add_client.sh <имя>` — новый клиент, выдаёт ссылку `tg://proxy`
- `./remove_client.sh <имя>` — отозвать доступ
- `./show_clients.sh` — все ссылки
- `./stop_proxy.sh`

Добавление и удаление клиентов подхватывается без перезапуска.

### Важно
- Клиентам нужен свежий Telegram: старые версии палятся ТСПУ по отпечатку TLS.
- Звонки через MTProto-прокси не работают (ограничение Telegram).
- Порт 443 занимает и `nineseconds/mtg`, и `xtls/xray` — на одном сервере запускайте что-то одно или меняйте `PORT`.
